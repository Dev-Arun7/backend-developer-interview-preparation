# Backend Developer Interview Preparation

A practical collection of technical interview questions, answers, coding problems and explanations for Python Backend Developers.

This repository is built through daily interview practice, covering beginner to advanced topics.

- Python fundamentals
- Data structures
- Object-Oriented Programming
- Functions and decorators
- Exception handling
- Advanced Python concepts

### 2. Django
- Django fundamentals
- Models and ORM
- Views and URLs
- Authentication and authorization
- Middleware
- Database optimization
- Real-world Django scenarios

### 3. SQL
- SQL fundamentals
- Joins and aggregations
- Subqueries
- Window functions
- PostgreSQL
- Database concepts and optimization

### 4. Problem Solving (DSA)
- Arrays and strings
- Hash maps
- Two pointers
- Sliding window
- Stack and queues
- Trees and graphs
- Algorithms

### 5. Backend & System Design
- REST APIs
- HTTP and networking
- Database design

- System design fundamentals

## How This Repository Works

1. Practise one interview question at a time.
2. Attempt the answer without looking up the solution.
3. Review the evaluation and corrected explanation.
4. Save the question and answer as a Markdown file.
5. Commit the updated notes to GitHub.

## Goal

Build a practical and beginner-friendly interview preparation resource that helps developers understand concepts, improve problem-solving skills and prepare for real technical interviews.

**Language:** Python, SQL, Markdown

**Database:** PostgreSQL
